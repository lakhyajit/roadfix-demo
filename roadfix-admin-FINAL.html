🔥 Firebase setup — 3 steps

1
Create Firebase project
Go to firebase.google.com → New project → name it roadfix-demo
Click the </> web icon → register app → copy your config object.
2
Enable Realtime Database
Firebase console → Build → Realtime Database → Create database → Start in test mode → Enable.
3
Paste your config in all 3 files
Open each HTML file, find AIzaSyC7B9o5Q_xyys8zS05MCM0461agxV6EtMQ and replace the entire firebaseConfig block with your real keys. Do this in:
• roadfix-customer-v3.html
• roadfix-mechanic-v3.html (coming)
• roadfix-admin-v2.html (this file)
Then re-upload all 3 to GitHub Pages.
